# Postmortem — Banque Atlas

## Principes
- Sans reproche : on analyse le système et les processus, jamais les personnes.
- Uniquement des faits présents dans la conversation ou renvoyés par les outils.
- Ce qui est inconnu (heure exacte, durée) est marqué "à compléter". Ne jamais inventer.

## Étapes
1. Lire le modèle templates/postmortem.md de cette skill avec lire_ressource_skill.
2. Si aucun diagnostic n'est présent dans la conversation, faire d'abord le triage (skill triage-incident).
3. Remplir chaque section du modèle, dans l'ordre.
4. Proposer au moins trois actions correctives, chacune avec une équipe responsable et une échéance "à définir".
